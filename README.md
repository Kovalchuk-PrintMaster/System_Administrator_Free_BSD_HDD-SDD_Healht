- `config/disk-health-audit.env.example`: порожній безпечний шаблон змінних, **не** серверний конфіг.
- `docs/RESTORE_UA.md`: порядок повернення файлу та окремих конфігурацій.
- `docs/ASSESSMENT_UA.md`: результати локальної статичної перевірки та обмеження.
- `docs/original-script.sha256`: контрольна сума першоджерела.

## Важливий стан оригіналу

Статична перевірка `bash -n` проходить, проте **в цьому файлі є закоментовані визначення функцій, на які посилається активний код** (`smart_overall_health`, `smartctl_attr_value`, `write_inventory`, `start_selftest` тощо). Для `collect/short/long` використовується Linux-дискавері через `lsblk`, `findmnt`, а в `probe` відсутні активні функції оцінки стану. На FreeBSD не можна обіцяти справний запуск лише за наявності цього файлу. **Не запускати `short` чи `long` для перевірки резервної копії.**

Поточний GitHub snapshot зберігає фактичний стан, але не стверджує, що оригінал працездатний. Перш ніж відновлювати виробничу службу, треба додатково зібрати окремо та перевірити реальний конфіг, команду/розклад запуску і локальні залежності. Не публікуйте реальний `.env` із токенами.

Див. [інструкцію з відновлення](docs/RESTORE_UA.md) і [аудит](docs/ASSESSMENT_UA.md).

## Перший push із Windows

Завантажте та розпакуйте підготовлений ZIP на сучасному Windows-комп'ютері, відкрийте PowerShell у папці та виконайте `& .\PUSH_FROM_WINDOWS.ps1` (якщо дозволено політикою виконання скриптів). Перед цим має бути встановлений Git for Windows і налаштована GitHub-автентифікація. Скрипт відмовиться працювати, якщо `main` уже містить коміти, щоб не перезаписати чужі зміни. Він перевіряє SHA256 локального оригіналу перед відправкою і SHA коміту після push. Ніяких змін на FreeBSD не вносить.

## Windows push r003: захист незміненої копії

Попередній запуск r001 зупинився на `git diff --cached --check`: рядок 1086 оригінального
`disk_health_audit.sh` містить кінцевий пробіл. Це особливість збереженого
оригіналу, **не причина змінювати джерело**. У r003 стандартна перевірка пробілів
застосовується до всіх нових файлів **крім** історичного `disk_health_audit.sh`,
а вихідний скрипт додатково перевіряється за SHA256 та exact Git blob (без фільтрів).
`.gitattributes` забороняє Git автоматично змінювати кінці рядків оригіналу.

Скрипт публікує лише 11 явно перелічених дозволених файлів; сторонні файли,
зокрема реальні `.env`, не переносяться до тимчасового Git-клону.
Запускати з **нової розпакованої папки r003**:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\PUSH_FROM_WINDOWS.ps1"
```
